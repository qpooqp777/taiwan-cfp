🚀 快速開始
================================================================================

第 1 步：設置 API 金鑰（2 分鐘）
  nano config/api_config.json
  # 填入你的 API 金鑰

第 2 步：測試連接（1 分鐘）
  python scripts/cfp_client.py test

第 3 步：開始使用（1 分鐘）
  python scripts/cfp_client.py query --product "電力"
  python scripts/cfp_client.py calculate --product "電力" --amount 1000 --unit "kWh"
